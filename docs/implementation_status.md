## 静态 LIO 回放

- 用户确认静止数据。首次实验配置地图边长 200 m、检测距离 100 m，违反局部地图边界条件并引发反复删点，静态轨迹严重发散。
- 单独把边长改为 1000 m 后，同一 bag 的末端相对位置变化由 700.419 m 降至 0.02035 m，过程中最大变化 0.03221 m。两轮均输出 297 条里程计，输入观察器收齐 300 帧点云与 6002 条 IMU。
- 新增独立的本机静态回放入口，启动前检查地图尺寸并要求明确采用实验外参。回放采用固定单位旋转和零平移，尚未完成 MID-360S 安装标定及动态精度验收。操作见 [静态回放](lio_static_replay.md)。

## 已执行的本机验证

环境：Ubuntu 24.04 / x86_64，ROS 2 Jazzy。实际完成：

- 根 CMake 构建、核心边界测试、监护策略测试和工具单元测试。
- colcon 编译 5 个包，执行 core/runtime/supervisor 测试并检查报告；无包或无实际测试不能报告成功。
- 真实 ROS 进程：默认禁用、许可后运动、保留原始 TTL、指令超时锁止、旧包不复活、新会话重新使能、独立 supervisor 退出后停止。
- 实际 launch：sim 输出静止禁用状态；replay 不加载运动进程；hardware 和非法模式拒绝启动，hardware_readonly 缺少真实配置时拒绝启动。

可重复命令见 [README](../README.md)。ROS 测试需要允许本机 DDS 套接字；此处验证全部使用 mock 平台，不存在实机 SDK 写入。

GitHub CI 的具体结果以对应提交的 Actions 记录为准；本文件不预先声明某个远程运行通过。ARM64 编译与真实 MID-360S 采集已有回传证据；Thor 资源评估、H2 状态接入和运动验收待完成。
